# Opposed d100 Skill Roll Calculator

A probability calculator for opposed d100 skill rolls, supporting multiple critical success rules and modifiers.

## Features

- Calculate win probabilities for two opposing skill checks
- Support for skill modifiers
- Alternative critical success rules (doubles vs multiples of 10)
- Detailed breakdown of critical success/failure outcomes
- Real-time probability visualization

## Run Locally

**Prerequisites:** Node.js and pnpm

1. Install dependencies:
   ```bash
   pnpm install
   ```

2. Run the development server:
   ```bash
   pnpm dev
   ```

3. Build for production:
   ```bash
   pnpm build
   ```
